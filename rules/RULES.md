# Engineering rules, with the tuition that bought each one

None of these are hypothetical. Each rule ends with the failure that paid
for it — anonymised, but real.

## 1. An algorithm implementation exists exactly once, in a module
Experiment scripts call it; they never re-implement it inline. *Tuition: the
same inner solver was informally rewritten twice inside experiment scripts —
once acquiring a sign flip, once a misapplied warm start. Both variants ran
fine and produced confident wrong numbers. The frozen module version never
broke again.*

## 2. Confirm liftoff 90 seconds after any detached launch
`nohup`/background jobs die silently in their first second (an unset
variable, a missing import). Wait 90 s, check the process lives, read the
log head. *Tuition: an evaluation "ran overnight" that had actually died
instantly on an argv-parsing bug; a full polling cycle was lost before
anyone looked.*

## 3. When a hyperparameter sweep looks flat, measure the force balance
Compute the gradient norms of each loss term at the initial point. Adaptive
optimizers normalise per-parameter scale, so a sweep that never crosses the
balance point between terms looks inert while being entirely on one side of
it. *Tuition: a regulariser weight was swept across four decades with no
effect — every value tested left the regulariser dominating the data term by
24× to 30,000×; the true balance point sat three decades below the sweep
floor.*

## 4. When the control group's number is absurd, the test is broken
If the sanity baseline in your experiment reports something impossible, stop
interpreting the treatment arm. *Tuition: a convergence-rate test showed
gradient descent at 13× its theoretical rate — the test problem secretly kept
iterates in a strongly convex subspace; the "interesting" arm's numbers were
meaningless too.*

## 5. A "wrong" adjoint/gradient can pass structured tests exactly
Verify linear-operator adjoints with random vectors; verify guards with
deliberate violations. All-ones and symmetric inputs can make a broken
adjoint pass with error exactly 0.0. *Tuition: an orientation bug produced a
transpose-mismatched operator whose error was invisible on near-symmetric
inputs and catastrophic on asymmetric ones — single-sample agreement proved
nothing because the error correlated with the content.*

## 6. Search-tool silence is not evidence
Before treating "no results" as "nobody did this", run the query on
something you know exists. Rate limits return convincing empty responses;
query drift returns plausible off-topic hits. *Tuition: five citation
look-ups in a row returned empty — looking exactly like five fabricated
references — because the API had silently rate-limited; a positive control
exposed it in one call.*

## 7. Read the recipe to the bottom before competing with it
Published baselines hide layers: the optimizer is not what you assume, the
loss is not what you assume, the metric convention and the operator differ.
*Tuition: matching one published classical baseline required seven distinct
corrections, each discovered by measurement; the final one was that the
benchmark's observations were generated by the very operator family used to
reconstruct — which redefined what "fair comparison" meant on that board.*

## 8. Separate the calibration of constants from the evaluation of methods
Physical/scale constants get fitted once, on calibration data, through an
interface that only admits scalars — so calibration cannot quietly become
per-sample fitting. *Tuition: a global scale factor of ~700 "fixed" a broken
geometry for one sample and hid the real bug for hours.*

## 9. Version-pin the unfashionable dependency
The ecosystem's current major release may be an API rewrite; the published
results you are reproducing were computed on the old one. *Tuition: a
reproduction stalled on a fresh install whose tomography module had moved
namespaces and broken array interop; the field's reference results needed
the previous major version.*

## 10. Persist numbers to disk before they become sentences
Sweep results that live only in a terminal buffer or an agent's return value
are one crash away from fiction. Results land in files, files land in
commits, sentences cite files. *Tuition: a full parallel sweep's final
ranking existed only in the orchestrator's return value; the commit meant to
record it reported "nothing to commit", which was the only warning that the
evidence for a headline claim was one process exit away from vanishing.*

## 11. No error bar, no effect
A confirmed gain is a paired difference with an interval, evaluated on the
unit of independence (patient / speaker / site), not a point estimate that
happened to land on the right side. Bootstrap within one split does not
measure split-to-split noise, and sample-level resampling under group
structure understates variance exactly when it matters. *Tuition: a gain
quoted confidently for days shrank to less than half and lost significance
the moment evaluation groups were made non-overlapping — the original
sample-level cross-validation had been inflated ~2.5× by group leakage, and
an in-split bootstrap had blessed it the whole time.*
